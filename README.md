# 📱 Skhokho Informal Buisness App

This repsoitory contains the Informal Buisness Web App Skhokho.

Skhokho allows informal buisness owners to:
1) Keep a close track of day-to-day earnings and spending.
2) Set aside cash to buy more stock.
3) Create Stokvels with ease for the sake of community betterment.
